# The GitHub release assets the how-to pages download, each with its sha256.
#
# scripts/docs_test.py serves these to the scenarios through its mirror,
# fetching each from github.com with scripts/fetch-pinned.sh, which checks
# the hash on every download and every cache hit and retries an outage for
# up to five minutes. `docs_test.py lint` fails a page that downloads a
# release asset no pin here matches, or that writes a sha256 not here.
#
# Each hash is the digest GitHub reports for the asset
# (gh api repos/<owner>/<repo>/releases/tags/<tag> --jq '.assets[] | .name + " " + .digest').
# The vcon-server archives' hashes are also the release's own SHA256SUMS.txt
# lines. To add a release or bump a tool, see the development page,
# website/content/docs/development.md, under "Pinned tool downloads".
# One line per asset: <sha256>, two spaces, <URL>.
