# Each package source an image's apt reads (an origin), and the hosts that
# hold the same files: the origin itself and at least one other, in the
# order apt tries them.
#
# One source a line: the origin, then its mirrors, separated by spaces. The
# origin is written as the image's source files write it; a mirror is an
# http:// address (a container has no certificates before its first
# install). Azure's mirror is the one GitHub's own runner images use. Each
# was read on port 80 from this project's host on 2026-11-10.
#
# Read by scripts/docs_test.py (the how-to runner, which asks each mirror
# from the host) and by scripts/apt-mirror-setup.sh (which a container runs
# before its first apt-get).
