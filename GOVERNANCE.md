# Governance

## The maintainer

vcon-server has one maintainer: the repository owner, NormB on GitHub. The
maintainer decides on every change. The maintainer:

- reviews and merges pull requests,
- publishes releases,
- sets the [roadmap](https://vcon-server.com/docs/roadmap/),
- handles security reports, as [SECURITY.md](SECURITY.md) describes,
- enforces the [Code of Conduct](CODE_OF_CONDUCT.md).

## Contributors

Anyone may open an issue or a pull request. A contributor:

- follows [CONTRIBUTING.md](CONTRIBUTING.md): the test written first, the
  hooks turned on, reserved test data only;
- signs the [Contributor License Agreement](CLA.md) before a first pull
  request merges;
- follows the [Code of Conduct](CODE_OF_CONDUCT.md).

## How decisions are made

The maintainer decides, in the open on the issue or the pull request. A
security report is handled in private until its fix is released, as
[SECURITY.md](SECURITY.md) sets out.

## Changing this document

This document changes by pull request, like any other file. If the project
gains maintainers, this document will say how they decide together.
